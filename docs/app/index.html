スマホでつくる、
触れる言葉。

日本語を入力すると点字に変換し、3Dプリンターで出力できる点字プレートのデータを作ります。専門知識は要りません。

App Store で入手使い方を見る

できること

日本語 → 点字

形態素解析で読みを求め、分かち書き・数字・記号を点字表記の規則に沿って変換します。読みはプレビュー上で修正できます。

3D プリンター用データ

点字プレートを OBJ と STL で書き出します。1行の文字数・1プレートの行数・厚さ・ドットの高さを設定できます。

1つの ZIP にまとめて保存

原文、点字データ、確認シート、3D モデルが1つの ZIP に入ります。

オフラインで動作

変換はすべて端末内で完了します。入力した文章が外部に送られることはありません。

ご利用の流れ

  1. 文章を入力点字プレビューが即座に表示されます。
  2. 「保存」を押すZIP ファイルが作られ、共有シートから「“ファイル”に保存」や AirDrop で保存できます。
  3. ZIP を展開して、OBJ/STL を 3D プリンターへZIP そのものは出力できません。ZIP の中身と取り出し方をご覧ください。

3D プリンターで出力するには: 保存した ZIP を展開し、中の plate_01.obj(または plate_01.stl)をスライサーで開きます。 → 詳しい手順
