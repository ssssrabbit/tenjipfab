使い方チュートリアル

文章を入力して保存するまでと、保存した ZIP から 3D プリンターで出力するファイルを取り出す方法です。

  • 1. 点字プレートを作る

1. 点字プレートを作る

  1. 文章を入力する画面下の「入力テキスト」に日本語を入力します。上のプレビューに点字が表示されます。
  2. 読みを確認する漢字の読みが違う場合は、プレビュー上でその語の読みを修正できます。
  3. 「保存」を押す画面下の青い「保存」ボタン、または右上のダウンロードアイコンです。共有シートが開きます。
  4. 保存先を選ぶ「“ファイル”に保存」を選ぶと、iPhone / iPad 内に保存されます。AirDrop でパソコンへ直接送ることもできます。

2. 出力設定

右上の歯車アイコンから変更できます。

項目内容
1行あたりの文字数1行に並べる点字のマス数。プレートの横幅が決まります。
1プレートあたりの行数1枚のプレートに入れる行数。文章が長いと複数のプレート(plate_01、plate_02…)に分かれます。
プレートの厚さ (mm)土台の厚さ。
ドットの高さ (mm)点の盛り上がり。出力物の触り心地に関わります。
点字言語日本語点字 / 英語点字の切り替え。アプリの表示言語とは独立しています。

3. 保存した ZIP の中身と、3D プリンター用ファイルの取り出し方

保存される ZIP ファイルは、そのまま 3D プリンターには使えません。ZIP は原文・点字データ・確認シート・3D モデルをまとめた「入れ物」です。展開して、中の .obj か .stl を取り出してスライサーで開いてください。

ファイル内容用途
plate_01.obj出力に使う点字プレートの3Dモデル(OBJ形式)。土台 (plate) と点 (dots) の2つのパーツを含みます。3Dプリンター(スライサー)
plate_01.stl出力に使う同じプレートの3Dモデル(STL形式)。3Dプリンター(スライサー)
braille.bse参考点字を ASCII 文字で表したテキストデータ(BSE 形式)。点字データを扱うソフトなど
guide_sheet.html参考プレートごとの点字と元の文字を並べた確認シート。ブラウザで開いて、墨字と見比べる
original_text.txt参考入力した原文。記録

.obj と .stl は同じ形を別の形式で書いたものです。どちらか一方を使えば足ります(スライサーが対応している方を選んでください)。

ZIP を展開する

環境方法
iPhone / iPad「ファイル」アプリで保存した ZIP をタップすると、同じ場所にフォルダとして展開されます。フォルダ内の plate_01.obj などを、共有ボタンから対応アプリやパソコンへ送ります。
MacZIP をダブルクリックすると同じ場所に展開されます。
WindowsZIP を右クリック →「すべて展開」。
Androidファイルマネージャーで ZIP をタップして展開します。

ヒント: 3D プリンターのアプリや、SD カード / USB メモリに ZIP のまま入れても読み込めません。展開した後の .obj / .stl を使います。

4. スライサーで出力する

  1. スライサーを開くSTL / OBJ に対応したスライサー(例: Bambu Studio、PrusaSlicer、Cura など)を使います。
  2. ファイルを読み込むplate_01.obj(または .stl)をドラッグ&ドロップ、またはメニューから開きます。寸法は mm です。複数パーツとして読み込むか尋ねられた場合は、プレートと点が一緒に出力されるように読み込んでください。
  3. 向きを確認する点が上を向くように置きます(読み込んだままで、点が上になる向きです)。
  4. スライスして出力する点の細かさを活かすため、積層ピッチは細かめを推奨します。
  5. 複数プレートの場合plate_02、plate_03… も同様に出力します。

点字の触り心地について: 出力した点が鋭いと指に痛いことがあります。設定の「ドットの高さ」を変えて試作し、実際に触って確かめるのがおすすめです。

よくある質問

ZIP を 3D プリンターに読み込ませたがエラーになる

ZIP は展開してから使います。中の plate_XX.obj または plate_XX.stl を読み込んでください。

HTML ファイルを出力してしまった / 開けない

guide_sheet.html は確認用です。3D プリンター用ではありません。ブラウザで開いてください。

保存した場所が分からない

共有シートで「“ファイル”に保存」を選んだ場合は、「ファイル」アプリで選んだ場所にあります。

データは外部に送信される?

されません。詳しくはプライバシーポリシーをご覧ください。
