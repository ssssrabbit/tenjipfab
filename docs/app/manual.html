1. 画面の構成

場所機能
上部のプレビュー入力した文章の点字を、プレートごとに表示します(Plate #1、Plate #2…)。
下部の「入力テキスト」文章を入力する欄と、青い「保存」ボタン。
右上のアイコン時計 = 履歴 / 歯車 = 出力設定 / ダウンロード = 保存(下部の「保存」ボタンと同じ)。

2. 入力とプレビュー

文章を入力すると、プレビューが自動で更新されます。1行の文字数と1プレートの行数は出力設定で決まり、文章が長いと複数のプレートに分かれます。

3. 読みの修正

漢字の読みは自動で判定するため、固有名詞などで誤ることがあります。プレビューの点字セルをタップすると「○○」の読みを修正する画面が開きます。ひらがなで読みを入力し、「保存」を押すと点字に反映されます。

4. 「変換できていません」の警告

入力のうち変換できない文字が多い(全体の約3割を超える)と、「多くの文字が変換できていません — 言語設定を確認してください」と表示されます。点字言語が入力の言語と合っていないことが多いので、警告をタップして点字言語を確認してください。変換できない文字は入力欄で色が変わります。

5. 出力設定

右上の歯車アイコンから開きます。変更はすぐにプレビューに反映されます。

項目範囲初期値
1行あたりの文字数5〜3010
1プレートあたりの行数1〜103
プレートの厚さ (mm)0.5〜2.0(0.1 刻み)1.0
ドットの高さ (mm)0.2〜1.0(0.05 刻み)0.4
点字言語日本語 / 英語日本語

ドットの高さは、出力物の触り心地に直結します。鋭く感じる場合は低めにして試作してください。

6. 履歴

「保存」を押した時の入力文章と設定が、履歴として端末内に残ります(新しいものから最大20件)。右上の時計アイコンから開き、項目をタップするとその文章と設定が復元されます。「クリア」ですべて削除できます。

7. 保存(ZIP の書き出し)

「保存」を押すと ZIP が作られ、共有シートが開きます。「“ファイル”に保存」や AirDrop などで保存してください。

ZIP はそのままでは 3D プリンターで出力できません。展開して中の plate_XX.obj または plate_XX.stl を使います。中身と取り出し方はチュートリアルをご覧ください。

8. 点字言語

設定で「日本語」と「英語」を切り替えられます。アプリの表示言語(端末の言語に従う)とは別の設定です。日本語の端末で英語の点字を作ることもできます。
