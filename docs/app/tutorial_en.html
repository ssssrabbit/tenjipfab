Tutorial

1. Make a braille plate

  1. Type your textEnter Japanese text in “Input Text” at the bottom. The braille appears in the preview above.
  2. Check the readingsIf a kanji reading is wrong, correct it from the preview.
  3. Tap “Save”Use the blue “Save” button or the download icon at the top right. The share sheet opens.
  4. Choose where to save“Save to Files” stores it on your iPhone / iPad. You can also AirDrop it straight to a computer.

2. Output settings

Open them with the gear icon at the top right.

SettingMeaning
Characters per lineNumber of braille cells per line; sets the plate width.
Lines per plateLines on one plate. Longer text is split into several plates (plate_01, plate_02…).
Plate thickness (mm)Thickness of the base.
Dot height (mm)How far the dots rise; affects how the print feels to the touch.
Braille languageJapanese or English braille. Independent of the app’s display language.

3. What’s inside the ZIP, and how to get the 3D-printer file

The saved ZIP can’t be sent to a 3D printer as is. It is a container holding your original text, braille data, a guide sheet and the 3D models. Extract it and take out the .obj (or .stl) file, then open that in your slicer.

FileContentsUse
plate_01.objprint this3D model of the braille plate (OBJ). Contains two parts: the base (plate) and the dots (dots).3D printer (slicer)
plate_01.stlprint thisThe same plate as an STL model.3D printer (slicer)
braille.bsereferenceThe braille as ASCII text (BSE format).Braille software, etc.
guide_sheet.htmlreferenceA sheet showing each plate’s braille next to the original characters.Open in a browser and compare with the text
original_text.txtreferenceThe text you entered.Record keeping

.obj and .stl describe the same shape in different formats. Use just one — whichever your slicer supports.

Extracting the ZIP

DeviceHow
iPhone / iPadIn the Files app, tap the ZIP. It is extracted into a folder next to it. Send plate_01.obj etc. from that folder to a compatible app or your computer with the share button.
MacDouble-click the ZIP; it is extracted next to it.
WindowsRight-click the ZIP → “Extract All”.
AndroidTap the ZIP in your file manager and extract it.

Tip: Putting the ZIP itself on an SD card or USB stick, or loading it into a printer app, won’t work. Use the extracted .obj / .stl.

4. Print with your slicer

  1. Open your slicerAny slicer that reads STL / OBJ works (for example Bambu Studio, PrusaSlicer or Cura).
  2. Load the fileOpen plate_01.obj (or .stl) by drag-and-drop or from the menu. Units are millimetres. If asked whether to load it as multiple parts, load it so the plate and dots are printed together.
  3. Check orientationThe dots should face up (they do as loaded).
  4. Slice and printA fine layer height is recommended to keep the dots crisp.
  5. Several plates?Print plate_02, plate_03… the same way.

About the feel of the dots: sharp printed dots can be uncomfortable on sensitive fingertips. Try different “Dot height” values, print a test and feel it yourself.

FAQ

My 3D printer or slicer gives an error when I load the ZIP

Extract the ZIP first and load plate_XX.obj or plate_XX.stl from inside.

I tried to print the HTML file / it won’t open

guide_sheet.html is a reference sheet, not printer data. Open it in a web browser.

I can’t find the saved file

If you chose “Save to Files”, it is in the location you picked in the Files app.

Is my data sent anywhere?

No. See the Privacy Policy.
