# 仕様メモ: 動作と点字規則

Blender アドオン(Tenji Braille)の動作と、実装した点字規則の根拠をまとめた開発者向けのメモです。使い方は [マニュアル](docs/index.html) を参照してください。

## 自動更新
- 「自動で更新」(既定でオン)のとき、テキストを打つたびに、分かち書き → 点字変換 → モデル上の生成までやり直す(入力が止まって約0.15秒後にまとめて実行)。
  対象モデルと枠を指定してあれば、空白の入れ方や行の折り返しがモデルにどう載るかを見ながらテキストを調整できる。
- 枠や対象モデルを動かしても、点は自動で作り直される(位置を見ながら調整できる)。
- テキストを編集しても、手で直した読み・空白の指定は同じ語に引き継ぐ。「読みを作り直す」で全てリセット。
- 1回の更新は、変換が数ms、生成が約20〜30ms(約190点・2万頂点のモデル)。辞書は起動時に裏で読み込む。
- Blender はラベル向けなので、ページや行数の上限の概念は持たない(連続プレート用の TS アプリとは用途が違う)。1行のセル数だけを設定する。
- 「サイズ」(寸法・出力サイズ)は折りたためるサブパネル。

## 区切りと折り返し
- **テキストに空白を直接入力して区切る**(基本の使い方)。N個の空白はちょうどNマスになる(規則で入る自動の空白には足さない)。入れなかった場所は規則で自動に決まる。
  「空白を自動で入れる」をオフにすると、テキストに入れた空白だけが使われる。
- 語の一覧の右の列で、語ごとに「後ろの空白」(自動 / なし / 1マス / 2マス)を個別に指定することもできる(テキストへの入力より優先)。
  読みの欄に空白を入れれば、語の途中でも区切れる。分かち書きの区切り方は辞書任せなので、ここで直す。
- **折り返し**: 既定は「点字の規則で折り返す」。「1行のセル数で並べる」を選ぶと、セルを左から並べ、1行のセル数に達したら折り返す(語の途中でも折り返し、「ー」は入れない)。
  濁点・拗音符・数符・外字符などの前置符号は本字と割らない。行頭に空白は置かず、段落の改行は守る。
  「点字の規則で折り返す」は、語を行にまたがせず、長すぎる語は音節で切って「ー」を付ける(TS アプリと同じ)。
- ※この2つは Python 版(Blender アドオン)のみの機能で、TS アプリには無い。

## 寸法とスケール
- 既定値は 点間 2.4mm / セル間 6.0mm / 点径 1.5mm / **点高さ 0.3mm**(3Dプリント出力は触読で痛いとの意見を受け低めに。0.25〜0.3 目安、可変)。行間 10・埋め込み 0.2 は暫定値。すべて可変。
- **出力サイズ (mm)**: 対象モデルの最長辺を3Dプリント時に何mmにするかを指定する。モデルを拡縮しても、
  点字は出力後に指定寸法になる。0 の場合はシーン単位(Unit Scale)をそのまま使う。
- モデルの倍率を変えたら「点字を生成」をやり直す。
- 実モデルでの確認: 寸法の単位が決まっていないクマの人形モデル(最長辺 2.0)に「出力サイズ 100mm」で後頭部に載せ、点高さ約0.3mm・点のメッシュは閉じた立体(非多様体辺0)であることを確認した。

## 曲面について
投影は枠方向への正射影。**平面〜緩やかな曲面向け**で、球のような強い曲面は対象外(最大入射角が警告値を
超えた点は報告される)。曲面に載せたい場合は、平面(または平面に近い面)に投影して作った点字メッシュを
Bend などで変形することを推奨する。

## 点字規則
参照: 文部科学省「点字表記法」第6章第3節(句読法) https://www.mext.go.jp/content/20231116-mxt_tokubetu01-000032539_25.pdf
- 句点・読点・疑問符・感嘆符は直前の語に続けて書く(前に空白を入れない)。
- 後ろの空白: 句点・疑問符・感嘆符(文末)は2マス、読点は1マス、文中の疑問符・感嘆符(助詞が続く)は1マス、閉じ括弧が続くときは空けない。
- 疑問符 = 点2,6 / 感嘆符 = 点2,3,5(同PDFの図から)。
- 括弧(`tenji/brackets.py`、点の配置は同PDFの図から):
  「」=第1カギ / カギの中のカギと『』=ふたえカギ / 〈〉=第2カギ / （）=第1カッコ /
  カッコの中のカッコ=二重カッコ / 〔〕［］=第2カッコ。内側は続けて書き、外側は分かち書き。
  文末(。？！)の直後の閉じ括弧の後ろは2マス。二重カッコ・第2カギは入れ子や記号の種類から自動で選ぶ(手動指定の UI はない)。
- 文中の「？」「！」の後に助詞以外が続く場合(例: 「えっ？本当？」)は文末とみなして2マスになる。自動判別はできない。
- 関係符号(`tenji/symbols.py`、点の配置は同PDFの図から):
  - 第1つなぎ符(点3,6): 数字の直後にア行・ラ行の仮名が続くとき、アルファベットの直後に仮名が続くときに挟む(例: 数100‐エン、外大X‐セン)。
  - 波線(〜 ～) = つなぎ符×2、前後を空けない。矢印(→) = 「ーーた」(点2,5 / 2,5 / 1,3,5)、前後1マス。
  - 大文字符(点6): 外字符の中で大文字の前に1つ、2字以上連続する大文字では2つ重ねる(外大大DOS、外大V)。
  - 接尾語・助数詞(品詞「名詞,接尾」: 円・時・分・線・玉 など)は直前の語に続けて書く(数8ジ、100エンダマ)。
- 外字系の記号(外字符 + 1セル): ％(点1,2,3,4) ＆(点1,2,3,4,6) ＃(点1,4,6) ＊(点1,6) ＠(点2,4,6)。半角も同じ。
  ％は数字の後ろに続ける。＃・＊は直後に数字が続くとき続ける(＊11)。＆・＠は前後1マス。
  ％＃＊の後ろに助詞・助動詞が続くときは1マス、接尾語など「ひと続きの語」が続くときはつなぎ符(20％‐ビキ)。
- 読点 = 点5,6 / 句点 = 点2,5,6(同PDFの図)。全角コンマ「，」も読点。※TS アプリは読点が点5になっていたため同PDFに合わせて修正済み。
- スラッシュ(点3,4): 英数字の `A/B` は1語として扱う。外字符で書くアルファベットの間は外字符が続く(外大大DOS／大V)。
  数字の間では前に外字符を置き、後ろの数字に数符を付け直す(数125 外／ 数85)。日付の略記(1/23)は区別できないためスラッシュのまま。
- 中点(点5): 直前に続け、後ろ1マス。数字の区切りには書かず、後ろの数字に数符を付ける(5・60 → 数5 数60)。アルファベット間は未対応。
  地名の段階の区切り(東京・神田)などは自動判別できないので中点のまま。
- 棒線(点2,5 ×2セル): 「―」「—」「─」の連なり2字につき1つ、前後1マス。点線(点2 ×3セル): 「…」1字につき1つ、前後1マス、句読点・閉じ符号が続くときは続ける。
- 数字の伏せ字「×」: 数字の直後の「×」1つにつき2セル(点5 / 点1〜6)。後ろの数字に数符は付けず(1××4)、後ろにかなが続くときはつなぎ符(20××‐ネン)、
  助詞・助動詞が続くときは1マス。掛け算(3×4)は伏せ字にしない(×が1つで後ろに数字が続く場合)。
  辞書には「×」を一時的に数字に置き換えて渡す(「20××年」の「年」をネンと読ませるため)。
- 括弧・波線・矢印・つなぎ符・大文字符・外字系の記号・伏せ字・句読点の規則は TS アプリ(`tenji-pfab-rn`)の `buildFlatCells` / `symbols.ts` にも入れてあり、TS の実コードとの照合テストで一致を確認している。
